# 小镇原创音频

这些音频由本仓库的 `scripts/generate-town-audio.py` 从零合成。旋律、和声编排、音色和提示音均为此项目创作，没有引用第三方录音、采样或已有歌曲。

| 文件 | 用途 | 时长 / 格式 |
| --- | --- | --- |
| `cheerful-loop.m4a` | 温暖、轻快的木琴旋律，拨弦和声、低音和轻沙锤 | 40 秒，96 BPM，16 小节；22.05 kHz 单声道 AAC，32 kbps |
| `tap.wav` | 轻按按钮 | 0.10 秒，22.05 kHz 单声道 PCM16 |
| `open.wav` | 打开建筑或面板 | 0.22 秒，同上 |
| `success.wav` | 完成操作或获得奖励 | 0.50 秒，同上 |

音乐尾音与两层轻微混响跨循环边界叠加，首尾用 8 毫秒包络抑制跳变。最终听感还取决于播放器的循环实现。背景音乐宜以较低音量播放；词语朗读等主要声音播放时应暂时压低或暂停背景音乐。

在 macOS 上重新生成：

```sh
python3 scripts/generate-town-audio.py
```

只依赖 Python 标准库和系统 `afconvert`。默认输出到 `miniapp/town-audio/audio/` 音频分包；可用 `--output` 指定另一个目录做复核。生成器会重新解码 AAC，报告实际时长、峰值、均方根电平、削波数量、循环边界跳变和文件大小，并检查音频总计小于 250 KB。合成使用固定随机种子；不同 macOS 编码器版本可能产生不同 AAC 字节。

当前四个音频合计 205,149 字节；AAC 解码时长 40.000 秒、峰值 −3.56 dBFS，所有文件均无削波。音乐首尾样本差为满刻度的 0.001495。
