# 小镇声音

小镇页面进入后播放 40 秒原创轻音乐，以木琴旋律和轻柔拨弦伴奏循环。顶部「小镇好心情」旁的音乐、音效按钮分别控制两类声音，选择保存在当前设备，重开小程序也会保留。首次默认开启，环境音遵循系统静音设置。

真实按钮点击配短音效，建造、小镇生活事件与角色购买成功后配完成提示。快速连点不会堆叠播放。单词朗读加载、播放期间暂停音乐和音效，朗读开关仍由学习页控制。

音乐只在小镇页面可见时播放。去学习、建造、我的家等页面时暂停，返回小镇后继续；小程序切到后台、系统音频中断时暂停，只有仍在小镇且音乐开启时才恢复。音频加载失败不影响操作，后续点击或重新进入页面可重试。

## 文件与分包

- `miniapp/utils/sound.js`：音量、开关持久化、播放器和生命周期管理。
- `miniapp/utils/sound-page.js`：页面点击音效，保持原有事件参数与返回值。
- `miniapp/town-audio/`：独立音频分包，随小镇页面预加载，通过异步 `require` 确认就绪。首次下载期间先正常显示小镇，过期的点击不补播。
- `scripts/generate-town-audio.py`：原创旋律与音效的生成、编码和声学检查，音频来源见分包内 README。

所有声音文件随小程序发布，不依赖外部音频地址。播放时使用前台音频实例，不申请后台音频权限。

## 检查

```sh
node --test scripts/sound-test.cjs scripts/sound-page-test.cjs scripts/page-loading-test.cjs scripts/learning-test.cjs
```

微信开发者工具和真机验收：

1. 进入已登录的小镇，听完整个 40 秒循环；连续点按钮确认音量柔和、没有音效叠加。
2. 分别关闭音乐和音效，重新进入小程序确认各自开关保留；关闭音效的操作立即安静，重新开启可以听到反馈。
3. 去学单词、返回小镇，再切后台、回前台，确认音乐只在小镇前台恢复。
4. 在听音练习中播放普通、慢速发音并快速换题，确认朗读不被按钮音效覆盖；检查设备静音开关。
5. 首次分包下载失败后恢复网络，点击按钮或重新进入小镇，确认音频可重试且页面业务始终可用。

自动化测试使用模拟的微信音频事件；实际听感、手机静音和系统中断行为需要在微信真机上检查。
