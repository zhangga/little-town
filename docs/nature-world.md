# 林溪秘境

从「我的方块世界」右侧点「林溪」进入；旧版「屋内生活」也有「去林溪探索」按钮。从沙盒进入时，「回方块世界」返回原来的页面与背包。

这是小家旁的一片独立自然探索区。画面保留方块人物和手作木屋，使用柔和的暖阳、天空散射光、实时柔化阴影、远景雾、渐变草地和细叶。树冠缓慢摇动，叶片和对应的影子一起随风变化。溪水在固定弯曲河道内以约 0.18 格／秒的视觉速度流动，叠加细小波纹和环境反光；水不会淹没陆地，沿木桥过河。

默认[方块世界](voxel-world.md)现在也有覆盖草地与异界的阳光、树影、风吹树叶和缓流水，并在世界矿洞中生成真实矿物。直接在世界里采集与合成即可，把白玻璃和镜子放回家不需要进入林溪。

## 走动和探索

- WASD／屏幕方向键走动，空格／跳跃按钮跳起，V／人称按钮切换第一、第三人称。
- 鼠标移动或拖动画面转视角；Esc 暂停鼠标转动，M 恢复。
- 靠近原木、石块、细沙或矿脉，按 E 或点采集按钮。每次敲击有进度，完成获得一组材料，24 秒探索时间后恢复。后台和打开背包时不计探索时间。
- B／材料背包打开配方或库存；走到入口左前方的木工桌旁才能合成。成品会自动放上工坊旁的展示台，灯笼会点亮矿洞入口。
- 石镐能采铜、铁和石英；铜镐进一步解锁银矿、紫水晶和萤石。沿石板路可走到洞口，洞内有暖色火把，跟随镜头在洞里自动拉近。

## 材料和合成

材料包括原木、石块、细沙、煤、铜矿石、铁矿石、石英、银矿石、紫水晶和萤石。10 张配方包括木板、石镐、铜锭、铁锭、铜镐、透明玻璃、白玻璃、银镜、灯笼和晶簇摆件。

透明玻璃清透；白玻璃呈乳白色、半透明，表面有天空和树林的环境反光。银镜使用实时平面反射，能看见身后的景物和角色；第一人称的主画面隐藏角色时，镜中仍显示角色。反射共用一个 384×384 纹理，每约 0.12 秒更新一次，在镜子背面或远离镜子时跳过更新。

配方为游戏玩法，不是现实材料的制作教程。

## 存档边界

林溪的材料、工具、收藏和采集恢复时间按「后端环境 + 登录用户」保存在当前设备，键为 `nature-world-v1:<backend>:<user-id>`。进入或返回默认方块世界时，玻璃、白玻璃和银镜会从这份库存转入同账号的世界背包，可以在家里自由放置、旋转镜面和挖下重新摆放。转移使用持久化待办与接收记录，保存失败可重试，不重复领取。其他材料与工具仍留在林溪；小镇金币和砖块不参与转移，也不提供跨设备同步。清除小程序数据会清除本机收藏。

每次采集和合成都先保存，再更新库存；保存失败时保留原材料，避免重试重复扣料。读取失败时禁止覆盖原有收藏。离开页面时保存当前探索时间。家具、购置与房间布局继续沿用原来的服务端逻辑。
