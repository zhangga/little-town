# 第一人称方块世界

从「我的家 → 方块世界」或点击住宅进入。原生小程序的 `home/pages/world/world` 是默认入口；原有 `room` 页面仍供立体小家与林溪探索使用。

画面来自角色眼睛，眼高 1.45 格，默认第一人称。五个房屋等级的实际占地仍为 7 / 9 / 12 / 16 / 20 格，实际楼层为 1 / 1 / 2 / 2 / 3 层。每层四格高，木楼梯能真正通往楼上，楼上也能摆家具。

## 怎么玩

| 操作 | 手机 | 键盘与鼠标 |
| --- | --- | --- |
| 行走 | 按住左下方向按钮；轻点走一小步 | WASD 或方向键；开发者工具中可用鼠标按住箭头 |
| 转头 | 拖动画面 | 按住拖动；指南中可开启鼠标移过转头 |
| 跳跃 | 跳跃 | 空格 |
| 开关门、使用家具、和动物打招呼、穿越星门 | 互动；靠近门会显示「开门 / 关门」 | E |
| 拿起已摆好的家具 | 对准家具后点拿起 | Q |
| 挖掘 | 点一下挖一块，按住连续挖 | 按住 F |
| 放置手里的方块、家具、房屋图纸或星门 | 放置 | R |
| 背包 / 合成 | 上方按钮 | B / C |
| 关闭面板 | × 或面板外 | Esc |

家具继续使用现有商场、金币价格和服务端购买确认。购买后返回世界，尚未摆放的新家具会直接拿在手里；已有的家具在背包中显示「已经摆好」，要先走近拿起。家具不能放进墙里、悬空、和其他家具重叠或把玩家包住。背包中的手持物会显示在第一人称手边。

门外是草地、树林、花与方块动物，包括绵羊、小猪、兔子、母鸡、狐狸和小鹿。西侧露天矿道通往浅层和深层矿洞；泥土下面有岩石、煤、铁、紫晶和其他矿物。最底层 Y=-20 是黑色基岩，不能挖掘。原来的住宅与草地商店也受到保护。

草地世界和星苔秘境共用自然效果：阳光与软阴影、随风摆动的树叶及其影子、东侧贯穿地图的浅河。河面有缓慢漂移的水纹、轻微起伏和环境反射；河水可以涉过，移动稍慢，走到岸边可以上岸。水流目前表现为固定河道中的缓慢表面动画，不是可泛滥的流体模拟。挖掘仍会选中水下河床，方块可以填入水格。

矿道东侧台阶旁能找到煤、铜、铁、石英、银、紫晶和萤石的露出矿脉，地下岩层也会生成这些矿物。`2 玻璃 + 1 石英矿` 合成白玻璃，`1 玻璃 + 2 银矿` 合成银镜，成品直接进入世界背包。回家后从「方块与图纸」拿出，对准地板或墙面按「放置」；银镜可旋转 90°，挖下会完整回收到背包，可重新摆放。楼上、自建房屋和异界使用同样的规则。

白玻璃映出周围天光和环境，近处可见的银镜会实时映出角色与房间。环境反射采用共享低分辨率探针，最多两面近处可见银镜同时更新平面倒影，远处镜子使用环境反射，以控制手机渲染成本。

采集的材料进入背包。配方包括原木变木板、石砖、玻璃、木门、楼梯、单层小屋图纸和双层木屋图纸。图纸需要平整且清空的草地，不能覆盖玩家、树、已有建筑或家具；新房子的门和楼梯可用，自己建的方块可以再挖掉。

月纹石和紫晶合成星门框，十个星门框加入回声方块和萤光石合成星门。星门需要四格宽、五格高的空地。靠近星门按 E 进入「星苔秘境」，那里有不同地表、暮紫木、晶叶，以及星角兽、跳跳方灵和晶翼蝶。回程门会同时生成，背包在两边共用。随时可以点「回家」返回原来的住宅。

## 存档边界

世界是本机单人存档，按后端环境与登录账号隔离。挖掘、放置、合成、造房、家具移动、门状态和维度会自动保存；行走时定期保存，离开页面前再保存一次。底部显示保存状态，空间不足时会明确显示失败并允许重试。

白玻璃位置、银镜位置与朝向也会保存。旧世界的挖掘和建造记录继续优先于新生成的河道和矿物。曾经在「林溪」合成的玻璃、白玻璃和银镜，在进入或返回方块世界时会转入世界背包；源背包扣除和世界接收记录可在保存失败后重试，不会重复领取。同一账号与同一后端环境才会转移。

世界存档没有上传服务器，不在不同手机间同步；清理小程序数据会清除世界。家具购买所有权和小镇金币仍由原服务端管理。已有的房间布置会在第一次进入时迁移，之后世界中的家具坐标以本机存档为准。

地图是有限世界：X/Z 为 -24 到 43，地下最低 -20，最高可放置到 26。每个维度保存独立的方块修改，共享物品与家具所有权。存档读取会检查版本、坐标、物品种类、家具所有权和基岩边界。

## 开发验证

无需新增依赖或数据库迁移，重新编译小程序即可接通入口。微信真机的 WebGL、触控和性能仍需验收。

2026-11-08 操作修复：在微信开发者工具 2.02.2609250 Stable / 基础库 3.17.4 中复现了原生 WebGL 画布覆盖整个操作层的问题。场景现在使用独立的矩形区域，按钮与目标说明位于画布外，准星由 WebGL 自己绘制；打开背包、指南或错误提示时隐藏画布，初始化和缩放均测量始终存在的场景容器。键盘事件接受微信的字符串修饰键字段（`altKey: 'false'`），避免把正常 WASD/E/F 当作系统快捷键丢弃。

在独立的原生测试项目中实际点击开门、长按方向键从屋内走到草地、走近树干挖出原木，并在背包中确认「原木 ×1」。短按移动、长按释放、取消触摸、面板隔离和按键字符串格式均有回归用例。浏览器检查使用实际页面初始化流程及微信格式的按键，保留 DOM 节点以覆盖真实按下/松开；320×568、390×752、768×900 和 768×390 下均断言画布不与操作按钮重叠。
