## 学习方式

| 方式 | 交互 |
| --- | --- |
| 新词闪卡 | 综合模式下打开每张新词卡时自动朗读一遍，可点击「听发音」「慢速听」重听；翻卡查看中文和简单例句，不单独计分 |
| 看图选词 | 根据图形选择英文；没有图形的自定义词改用看中文选英文 |
| 看词选义 | 根据英文选择中文，支持重听发音 |
| 听音辨词 | 听完音频后选择英文；答题前不展示题干单词或中文 |
| 字母拼词 | 按顺序点选字母；支持重复字母、词间空格、撤回和重拼 |
| 例句填空 | 用简单英文句子与中文提示练习单词的用法 |
| 词义配对 | 一轮结束后配对英文和中文；每屏最多 5 对，更多词分组显示 |

综合闯关在每轮打乱五种题型的顺序。也可选择「听力小站」或「拼写工坊」进行专项练习。没有音频、例句或可用拼写格式的单词会退回可完成的认词题。

首次答错的单词进入本轮末尾的拼写巩固，每词再练一次。正常学习只有首次闯关调用原有答题接口、计成绩和单题奖励；闪卡、错词巩固与配对不会重复发单题奖励或提升复习等级。奖励文案使用接口实际返回值，包含每日上限及完成奖励。

答题保存期间不能进入下一题。当前后端接口没有幂等键，网络超时后不自动重发；页面会提示本题奖励未确认，完成页汇总未确认题数。既有后端仍接收客户端的 `is_correct`，本次没有改变判分协议。

## 每日目标与继续学习

每日目标（默认 5 词）用于每轮安排与成长奖励，不限制每天学习的轮数。完成后首页仍提供“继续学习”，结算页提供“继续学习下一轮”；从其他 tab 返回已经完成的学习页会重新准备下一轮，未完成的题目仍保留。

当前年级没有新词和可领奖的到期复习词时，会提供“自由复习”：从本人已学的有效英语词中按 ID 分组轮换，到末尾后从头补齐，每组没有重复词。当天已领过答对奖励的到期词也进入自由复习，避免反复出现无奖励的普通任务；次日仍可进入正常间隔复习。

自由复习每完成一轮题目、错词巩固和配对后，奖励 **4 块砖、12 金币**；每天最多奖励 **3 轮**，共 **12 块砖、36 金币**。这是独立额度，不占正常答题每日 20 块砖的额度，也不重复发每日目标完成奖励。额度领满后仍能继续练习。自由复习不改变间隔复习计划、不增加小镇长成长。

答题顶部区分“本轮已到账”和“完成本轮可得”：正常学习实时累计接口确认的奖励；自由复习在结算前展示整轮 4 砖、12 金币与已答／答对进度，完成后才显示实际到账。已领满、同词当天已领奖以及保存结果未确认时显示具体原因，预计奖励不写入钱包。

学单词页面顶部常显「今日奖励剩余」，分别显示答题砖块（每日 20 次）、自由复习整轮奖励（每日 3 次）和每日目标奖励（每日 1 次）的剩余次数。选路线、闪卡、答题、巩固、配对和结算页均保留显示。只在服务端确认答题或整轮结算后更新，目标完成额外获得的 10 砖不占答题次数；答错、同词当天重复领奖或保存失败不会在本地预扣次数。答题砖块额度用完后，金币仍按原规则发放，学习可继续。

后端为每轮签发绑定用户、日期和单词的票据，逐题保存进度，结算时锁定用户行并检查全部词已答、是否已结算及当天额度。重复点击、同一轮多设备重试只发一次；结算响应丢失可手动用同一票据重新确认。题组票据当天有效，不能充当登录 token。判题及配对完成仍由客户端负责，与现有答题协议一致。

`GET /api/v1/learn/daily-words` 接受可选 `practice_after` 游标，响应包含 `session_kind`（learning / practice / empty）和 `practice_next_id`。所有模式都返回 `practice_rewards`（每轮金额、每日上限、已奖励及剩余轮数）、`bricks_today`、`daily_brick_cap`、`bricks_per_correct`、`bonus_claimed`，供页面展示剩余次数；昨日答题砖块不计入今日额度。自由复习另返回 `practice_token`。`POST /learn/practice/answer` 保存单词进度，`POST /learn/practice/complete` 结算本轮。只在没有正常学习任务时使用游标；有新词或当天未领奖的到期词优先下发。删除的词不再进入题组。

需要同时更新后端与小程序：新增 `practice_rounds` 表，重启开启 `AUTO_MIGRATE` 的后端会自动建表，关闭时需先迁移；无需重新导入词库。正常学习的成长、同词每日奖励和砖块上限保持原规则。回归覆盖整轮发奖、每日上限、跨天恢复、并发和重复领取、保存失败与手动确认、旧页面回调隔离。

保存成功后，答对约停留 1.6 秒、答错约停留 3.5 秒，然后自动前进；正常播放中的发音会等读完。反馈和「继续探险」固定在屏幕底部，无须下滑。点击「停留看看」或手动重听会暂停跳转，可恢复自动或直接继续。切后台、保存失败时也会停留，避免看不到反馈就被跳过。

## 发音资源

- 240 条种子记录包含 233 个不同英文词，全部附带常速和慢速美式英语合成发音，共 466 个 MP3。
- 原有 25 词的 50 个 MP3 保留在 `miniapp/audio/words/`；新增 208 词的 416 个 MP3 放入 `miniapp/textbook-audio/words/` 分包。学习页预加载该分包，播放器通过小程序支持的 `require('../textbook-audio/ready.js', success, fail)` 等待分包加载完成后再播放，离开页面或换词会忽略过期回调；下载失败可重试。`wx.loadSubpackage` 是小游戏接口，不能用于本小程序。
- `project.config.json` 的 `packOptions.include` 明确包含两个音频目录，确保按单词动态生成的 MP3 路径不会被无依赖文件过滤移除。
- 原始音频来自 Windows `System.Speech` 的 `Microsoft Zira Desktop`（en-US，常速 -1、慢速 -4）；新增音频来自 macOS 的 Eddy（en-US，常速 165、慢速 110 词／分钟），以 16 kHz 单声道、24 kbps MP3 编码。这些均为合成语音，慢速使用独立音频。
- 音频随小程序资源包分发，无须请求第三方 TTS，也无须新增数据库字段。首次进入学习页需要下载课本发音分包。
- `miniapp/data/word-content.js` 合并原始例句和课本内容；`miniapp/utils/learning.js` 按规范化单词映射音频文件名，`let's` 对应 `lets.mp3`。
- 自定义单词如有 `audio_url`，可直接播放；没有音频时明确显示缺失状态，并跳过听力题。远端音频应使用可访问的 HTTPS 地址，并在小程序后台配置相应域名。
- 关闭「加入听力和自动朗读」后，综合模式不安排听力题，新词卡和答案均不自动朗读；仍可手动点击发音按钮。翻卡不会重复触发朗读，切到下一张新词卡会读新词；离开学习页会停止播放。
- 每页只持有一个播放器，切题、切后台或退出时销毁，播放失败可重听，听力题可切换为认词题。

更新词库或语音时，在安装英语语音及 FFmpeg 的 Windows 环境运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/generate-word-audio.ps1 -Ffmpeg 'C:\path\to\ffmpeg.exe'
```

Windows 脚本将 WAV 中间文件写入 `output/word-audio-source/`，把 24 kbps MP3 写入各自的资源包。macOS 可用以下命令补齐缺少的文件（默认保留现有音频，自动选择已安装的 Samantha 或 Eddy 美式英语语音）：

```bash
python3 scripts/generate-word-audio-macos.py --ffmpeg /path/to/ffmpeg
```

macOS 脚本使用临时目录存放中间音频，完成后自动清理。新增词条时同步补充课本内容与后端种子数据，并提交生成的 MP3；主包与每个分包均须小于 2 MiB。
