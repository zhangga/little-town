# 多题型学习与读音

重新编译小程序后，从「学单词」进入新的路线选择页。后端接口保持兼容，现有账号和词库无需重新导入。

## 学习方式

| 方式 | 交互 |
| --- | --- |
| 新词闪卡 | 综合模式下先看单词、听发音，翻卡查看中文和简单例句；不单独计分 |
| 看图选词 | 根据图形选择英文；没有图形的自定义词改用看中文选英文 |
| 看词选义 | 根据英文选择中文，支持重听发音 |
| 听音辨词 | 听完音频后选择英文；答题前不展示题干单词或中文 |
| 字母拼词 | 按顺序点选字母；支持重复字母、词间空格、撤回和重拼 |
| 例句填空 | 用简单英文句子与中文提示练习单词的用法 |
| 词义配对 | 一轮结束后配对英文和中文；每屏最多 5 对，更多词分组显示 |

综合闯关在每轮打乱五种题型的顺序。也可选择「听力小站」或「拼写工坊」进行专项练习。没有音频、例句或可用拼写格式的单词会退回可完成的认词题。

首次答错的单词进入本轮末尾的拼写巩固，每词再练一次。正常学习只有首次闯关调用原有答题接口、计成绩和单题奖励；闪卡、错词巩固与配对不会重复发单题奖励或提升复习等级。奖励文案使用接口实际返回值，包含每日上限及完成奖励。

答题保存期间不能进入下一题。当前后端接口没有幂等键，网络超时后不自动重发；页面会提示本题奖励未确认，完成页汇总未确认题数。既有后端仍接收客户端的 `is_correct`，本次没有改变判分协议。

## 每日目标与继续学习

每日目标（默认 5 词）用于每轮安排与成长奖励，不限制每天学习的轮数。完成后首页仍提供“继续学习”，结算页提供“继续学习下一轮”；从其他 tab 返回已经完成的学习页会重新准备下一轮，未完成的题目仍保留。

当前年级没有新词和可领奖的到期复习词时，会提供“自由复习”：从本人已学的有效英语词中按 ID 分组轮换，到末尾后从头补齐，每组没有重复词。当天已领过答对奖励的到期词也进入自由复习，避免反复出现无奖励的普通任务；次日仍可进入正常间隔复习。

自由复习每完成一轮题目、错词巩固和配对后，奖励 **4 块砖、12 金币**；每天最多奖励 **3 轮**，共 **12 块砖、36 金币**。这是独立额度，不占正常答题每日 20 块砖的额度，也不重复发每日目标完成奖励。额度领满后仍能继续练习。自由复习不改变间隔复习计划、不增加小镇长成长。

答题顶部区分“本轮已到账”和“完成本轮可得”：正常学习实时累计接口确认的奖励；自由复习在结算前展示整轮 4 砖、12 金币与已答／答对进度，完成后才显示实际到账。已领满、同词当天已领奖以及保存结果未确认时显示具体原因，预计奖励不写入钱包。

后端为每轮签发绑定用户、日期和单词的票据，逐题保存进度，结算时锁定用户行并检查全部词已答、是否已结算及当天额度。重复点击、同一轮多设备重试只发一次；结算响应丢失可手动用同一票据重新确认。题组票据当天有效，不能充当登录 token。判题及配对完成仍由客户端负责，与现有答题协议一致。

`GET /api/v1/learn/daily-words` 接受可选 `practice_after` 游标，响应包含 `session_kind`（learning / practice / empty）和 `practice_next_id`。自由复习还返回 `practice_token` 与 `practice_rewards`（每轮金额、每日上限、已奖励及剩余轮数）。`POST /learn/practice/answer` 保存单词进度，`POST /learn/practice/complete` 结算本轮。只在没有正常学习任务时使用游标；有新词或当天未领奖的到期词优先下发。删除的词不再进入题组。

需要同时更新后端与小程序：新增 `practice_rounds` 表，重启开启 `AUTO_MIGRATE` 的后端会自动建表，关闭时需先迁移；无需重新导入词库。正常学习的成长、同词每日奖励和砖块上限保持原规则。回归覆盖整轮发奖、每日上限、跨天恢复、并发和重复领取、保存失败与手动确认、旧页面回调隔离。

保存成功后，答对约停留 1.6 秒、答错约停留 3.5 秒，然后自动前进；正常播放中的发音会等读完。反馈和「继续探险」固定在屏幕底部，无须下滑。点击「停留看看」或手动重听会暂停跳转，可恢复自动或直接继续。切后台、保存失败时也会停留，避免看不到反馈就被跳过。

## 发音资源

- 初始词库 25 个词全部附带常速和慢速美式英语合成发音，共 50 个 MP3，合计约 571 KiB。
- 发音随包存放于 `miniapp/audio/words/`，无须联网请求第三方 TTS，也无须新增数据库字段。
- 来源为 Windows `System.Speech` 的 `Microsoft Zira Desktop`（en-US）。这是合成语音，不是真人录音。
- 常速、慢速分别以语速 -1、-4 合成；慢速使用独立音频，避免变速导致音调变化。
- `miniapp/data/word-content.js` 保存配套例句；`miniapp/utils/learning.js` 按规范化单词映射音频文件名。
- 自定义单词如有 `audio_url`，可直接播放；没有音频时明确显示缺失状态，并跳过听力题。远端音频应使用可访问的 HTTPS 地址，并在小程序后台配置相应域名。
- 关闭「加入听力和自动朗读」后，综合模式不安排听力题，也不自动读答案；仍可手动点击发音按钮。
- 每页只持有一个播放器，切题、切后台或退出时销毁，播放失败可重听，听力题可切换为认词题。

更新初始词库或语音时，在安装英语语音及 FFmpeg 的 Windows 环境运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/generate-word-audio.ps1 -Ffmpeg 'C:\path\to\ffmpeg.exe'
```

脚本把 WAV 中间文件写入 `output/word-audio-source/`，把 48 kbps MP3 写入小程序资源目录。新增词条时同步补充 `word-content.js`，并提交生成的 MP3。

## 验证

```powershell
node --test scripts/learning-test.cjs
```

测试覆盖题型轮换、无歧义选项、自定义词降级、多词和重复字母拼写、完整学习流程、错词及配对不重复发奖、重复点击、保存失败、切后台、过期音频回调，以及 50 个音频资源的存在性与体积。

本次还使用本机微信开发者工具的 WXML/WXSS 编译器完成编译，渲染检查了 12 种页面状态，并用 FFmpeg 解码检查所有音频。浏览器布局预览不等于真机验证；仍需在 iOS / Android 微信中检查常速和慢速播放、静音开关、蓝牙耳机、切后台与恢复。
