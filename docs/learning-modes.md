# 多题型学习与读音

重新编译小程序后，从「学习」进入英语路线选择页，也可以通过顶部三个科目进入学校。后端接口保持兼容。新增课本词库需执行下方导入命令；原有账号与学习进度保留。

## 学校三科课堂

学校页面位于 `school/pages/classroom/classroom` 分包。点小镇里已建造的学校，再点「去上课 · 语文 / 数学 / 英语」即可进入；底部「学习」页顶部也提供三个科目入口，不需要先建好学校。

- **语文**：内置基础汉字、拼音和组词。电脑端通过鼠标拖动模拟触摸写字，手机用手指书写；田字格支持范字显示/隐藏、撤销一整笔、清空。必须先有笔迹才能完成。这里记录练写次数，请孩子对照范字自行检查，未实现笔顺识别或字形自动评分。
- **数学**：每轮 5 题，可选 20 以内加减法、100 以内加减法、乘除法。直接在输入框打数字，点击「检查答案」或键盘完成键提交；空白不算作零，重复点击不会重复计数。乘除法使用九九范围且除法可整除。答错后显示正确答案，轮末可只重练错题。
- **英语**：中文提示、键盘拼写、内置词的常速/慢速发音；拼写忽略大小写、首尾空格及连续空格。未配录音的自选词可以继续拼写。入口「去原来的英语闯关」连接原有学习、复习流程，与学校英语共用奖励额度。

### 更多玩法、课堂小练与小讲播

每科首页提供 4 种玩法，每次练 5 项；原来的书写和数字输入方式保留。

| 科目 | 玩法 |
| --- | --- |
| 语文 | 田字格写字、拼音找朋友、词语填空、短文小侦探 |
| 数学 | 数字口算、比大小、算式补空、生活应用题 |
| 英语 | 单词拼写、词义配对、听音选意思、句子小积木 |

「课堂小练」组合本科的 5 道不同题型，结束后按题型显示答对数，支持错题再练。语文小练中的拼音、填空、阅读题正常判分，手写仍是自我检查，不混作正确率。最近 12 轮小练记录保存在本机，首页显示本科上次的小练结果。打开本题提示或听方法讲解会标记为“已看讲解”，小练回顾会显示借助讲解完成的题数。

听音选意思需完整播放一次后才能检查；音频失败时可以明确切换成看词练习。句子小积木通过点击词块排列，支持撤销一个词、重新排，重复点击不会复用同一个词块。

「阿禾小讲播」包含 12 个方法主题，每课 3 步，共 36 段普通话合成音频。每步都有板书和完整字幕，可以播放、暂停、继续、从头重听、0.8 倍速听；点下一步才继续讲，最后可直接开始对应玩法。离开页面、切后台、切科目或换题时停止讲解，避免与单词发音同时播放。

练习中的「给我一点提示」展示本题的具体思路；数学会列出实际算式、答案和检查方法，阅读会指出原文证据。点「不会，听讲解」进入对应的方法课，返回时保留原题、输入答案、已排列的词块和笔迹。小讲播是预制方法课，并非实时语音解答任意照片；本题具体解法可在返回后查看。

讲稿和板书位于 `school/data/mini-lessons.js`，语音文件随 school 分包提供，不需要第三方 TTS 服务或密钥。修改文稿后运行 `python3 scripts/generate-school-audio.py`，脚本使用 macOS `say`（Tingting）与 `afconvert` 生成 AAC/M4A；讲稿指纹变化时只重建对应音频。`school/audio/manifest.json` 记录音频时长、体积与校验和。`project.config.json` 显式保留音频目录，避免动态路径被未使用资源过滤删除。

### 添加拍照教材

1. 打开「我的教材 → 添加一份教材」，在上方选择科目。
2. 可拍照或从相册选一张课本照片；照片用于对照，**目前不自动 OCR 识别**。也可以不附照片。
3. 填上教材名字和要练的内容：语文写汉字或句子（自动拆字、去重）；数学每行一道算式，如 `12 + 8 =`、`20 ÷ 5 =`；英语每行英文和中文，如 `apple 苹果`、`ice cream 冰淇淋`。
4. 保存后点该份教材的「开始练习」。三科都按录入内容出题，附图时练习中可随时点开原照片。数学仅接受答案在 0–9999 的非负整数题，输入中的现成答案不用于判分，按算式重新计算。

每份最多 40 项、最多保存 16 份。照片通过文件系统复制到持久本机目录，保存失败会保留编辑内容并清理新副本；删除教材时同时清理其照片。教材、照片和课堂练习次数按后端与账号隔离保存在当前设备，暂不跨设备同步；清理小程序数据会丢失这些本机内容。课堂奖励写入服务端小镇钱包；课堂成绩仍保存在本机，不增加原英语间隔复习、居民经验或家长学习统计。

### 三科独立奖励

语文、数学、英语分别采用相同规则，复用原英语奖励常量：

| 奖励 | 每科规则 | 每科每日次数 |
| --- | --- | --- |
| 答题 / 练写 | 答对一道题，或完成一个汉字练写，获得 1 砖 + 5 金币；同题当天不重复发放 | 20 次砖块奖励，领满后新题金币仍按原规则发放 |
| 每日完成 | 当天完成 10 道不同题目（可跨多个五题小练），额外 10 砖 + 10 金币 | 1 次 |
| 整轮复习 | 首页「整轮复习」默认混合 10 题，全部作答后获得 4 砖 + 12 金币 | 12 轮 |

每日目标与整轮复习题量使用后端 `DAILY_WORD_COUNT`，默认为 10。答错也算一次学习进度，之后另开学习轮纠正可获得一次该题答对奖励；错题巩固按钮和只听讲播不重复发奖。语文练写不自动评分，完成奖励以已有笔迹并点击「我写好了」为依据。教材练习与课堂小练都参与本科答题及每日目标奖励。每天每科最多获得 78 砖，三科合计 234 砖；领满后仍可学习。

新旧英语入口共用原有答题 20 砖、每日完成日期和复习 12 轮额度。已识别的同词同义词条即便跨年级有不同目录 ID，也不会因切换入口再领奖。语文、数学各自计数，学完一科不占用另一科次数；结算页可直接切换科目。

后端新增 `school_rounds`、`school_studies`、`school_dailies` 三表，与购买、建造及旧英语使用同一用户行锁。重启启用 `AUTO_MIGRATE` 的后端会自动建表；关闭自动迁移的环境应先执行迁移。四个鉴权接口为 `GET /learn/school/rewards`、`POST /learn/school/start`、`POST /learn/school/answer`、`POST /learn/school/complete`，统一前缀 `/api/v1`。开始题组绑定账号、科目、类型、题目与日期；逐题按题组和索引去重，整轮必须全部作答才能结算。答题是否正确沿用现有小程序上报机制，服务端校验题组进度并计算奖励，不接受客户端指定发奖数量。

页面只展示服务端确认的到账金额，待确认提交按后端与账号保存在本机。网络失败可点「重新确认奖励」，或重进学校恢复；复用相同题组 ID，重复提交不再次发奖。切科后的旧响应只更新对应科目，不覆盖当前题组。跨天题组返回 410，已到账部分保留，未同步部分不补发，页面提示开始新一轮；每日额度按后端配置的时区恢复。清理本机数据会丢失尚未确认的提交，已到账钱包保留。

## 学习方式

| 方式 | 交互 |
| --- | --- |
| 新词闪卡 | 综合模式下打开每张新词卡时自动朗读一遍，可点击「听发音」「慢速听」重听；翻卡查看中文和简单例句，不单独计分 |
| 看图选词 | 根据图形选择英文；没有图形的自定义词改用看中文选英文 |
| 看词选义 | 根据英文选择中文，支持重听发音 |
| 听音辨词 | 听完音频后选择英文；答题前不展示题干单词或中文 |
| 字母拼词 | 按顺序点选字母；支持重复字母、词间空格、撤回和重拼 |
| 例句填空 | 用简单英文句子与中文提示练习单词的用法 |
| 词义配对 | 一轮结束后配对英文和中文；每屏最多 5 对，更多词分组显示 |

综合闯关在每轮打乱五种题型的顺序。也可选择「听力小站」或「拼写工坊」进行专项练习。没有音频、例句或可用拼写格式的单词会退回可完成的认词题。

首次答错的单词进入本轮末尾的拼写巩固，每词再练一次。正常学习只有首次闯关调用原有答题接口、计成绩和单题奖励；闪卡、错词巩固与配对不会重复发单题奖励或提升复习等级。奖励文案使用接口实际返回值，包含每日上限及完成奖励。

答题保存期间不能进入下一题。当前后端接口没有幂等键，网络超时后不自动重发；页面会提示本题奖励未确认，完成页汇总未确认题数。既有后端仍接收客户端的 `is_correct`，本次没有改变判分协议。

## 每日目标与继续学习

每日目标（默认 10 词）用于每轮安排与成长奖励，不限制每天学习的轮数。正常学习和自由复习每轮默认安排 10 个不同单词，词库不足时按实际可用数量下发；配对仍按每组最多 5 对分批展示。可用 `DAILY_WORD_COUNT` 调整题量，已有部署如显式配置为 5，需同步改为 10 并重启后端。完成后首页仍提供“继续学习”，结算页提供“继续学习下一轮”；从其他 tab 返回已经完成的学习页会重新准备下一轮，未完成的题目仍保留。

当前年级没有新词和可领奖的到期复习词时，会提供“自由复习”：从本人已学的有效英语词中按 ID 分组轮换，到末尾后从头补齐，每组没有重复词。当天已领过答对奖励的到期词也进入自由复习，避免反复出现无奖励的普通任务；次日仍可进入正常间隔复习。

自由复习每完成一轮题目、错词巩固和配对后，奖励 **4 块砖、12 金币**；每天最多奖励 **12 轮**，共 **48 块砖、144 金币**。这是独立额度，不占正常答题每日 20 块砖的额度，也不重复发每日目标完成奖励。额度领满后仍能继续练习。自由复习不改变间隔复习计划、不增加小镇长成长。

答题顶部区分“本轮已到账”和“完成本轮可得”：正常学习实时累计接口确认的奖励；自由复习在结算前展示整轮 4 砖、12 金币与已答／答对进度，完成后才显示实际到账。已领满、同词当天已领奖以及保存结果未确认时显示具体原因，预计奖励不写入钱包。

学单词页面顶部常显「今日奖励剩余」，分别显示答题砖块（每日 20 次）、自由复习整轮奖励（每日 12 次）和每日目标奖励（每日 1 次）的剩余次数。选路线、闪卡、答题、巩固、配对和结算页均保留显示。只在服务端确认答题或整轮结算后更新，目标完成额外获得的 10 砖不占答题次数；答错、同词当天重复领奖或保存失败不会在本地预扣次数。答题砖块额度用完后，金币仍按原规则发放，学习可继续。

后端为每轮签发绑定用户、日期和单词的票据，逐题保存进度，结算时锁定用户行并检查全部词已答、是否已结算及当天额度。重复点击、同一轮多设备重试只发一次；结算响应丢失可手动用同一票据重新确认。题组票据当天有效，不能充当登录 token。判题及配对完成仍由客户端负责，与现有答题协议一致。

`GET /api/v1/learn/daily-words` 接受可选 `practice_after` 游标，响应包含 `session_kind`（learning / practice / empty）和 `practice_next_id`。所有模式都返回 `practice_rewards`（每轮金额、每日上限、已奖励及剩余轮数）、`bricks_today`、`daily_brick_cap`、`bricks_per_correct`、`bonus_claimed`，供页面展示剩余次数；昨日答题砖块不计入今日额度。自由复习另返回 `practice_token`。`POST /learn/practice/answer` 保存单词进度，`POST /learn/practice/complete` 结算本轮。只在没有正常学习任务时使用游标；有新词或当天未领奖的到期词优先下发。删除的词不再进入题组。

需要同时更新后端与小程序：新增 `practice_rounds` 表，重启开启 `AUTO_MIGRATE` 的后端会自动建表，关闭时需先迁移；无需重新导入词库。正常学习的成长、同词每日奖励和砖块上限保持原规则。回归覆盖整轮发奖、每日上限、跨天恢复、并发和重复领取、保存失败与手动确认、旧页面回调隔离。

保存成功后，答对约停留 1.6 秒、答错约停留 3.5 秒，然后自动前进；正常播放中的发音会等读完。反馈和「继续探险」固定在屏幕底部，无须下滑。点击「停留看看」或手动重听会暂停跳转，可恢复自动或直接继续。切后台、保存失败时也会停留，避免看不到反馈就被跳过。

## 发音资源

- 240 条种子记录包含 233 个不同英文词，全部附带常速和慢速美式英语合成发音，共 466 个 MP3。
- 全部 466 个 MP3 统一放入 `miniapp/textbook-audio/words/` 分包；原有 50 个 MP3 仅移动位置，音频字节不变，为主包腾出 584,320 字节。学习页预加载该分包，播放器通过小程序支持的 `require('../textbook-audio/ready.js', success, fail)` 等待分包加载完成后再播放，离开页面或换词会忽略过期回调；下载失败可重试。`wx.loadSubpackage` 是小游戏接口，不能用于本小程序。
- `project.config.json` 的 `packOptions.include` 明确包含单词音频目录，确保按单词动态生成的 MP3 路径不会被无依赖文件过滤移除。
- 原始音频来自 Windows `System.Speech` 的 `Microsoft Zira Desktop`（en-US，常速 -1、慢速 -4）；新增音频来自 macOS 的 Eddy（en-US，常速 165、慢速 110 词／分钟），以 16 kHz 单声道、24 kbps MP3 编码。这些均为合成语音，慢速使用独立音频。
- 音频随小程序资源包分发，无须请求第三方 TTS，也无须新增数据库字段。首次进入学习页需要下载课本发音分包。
- `miniapp/data/word-content.js` 合并原始例句和课本内容；`miniapp/utils/learning.js` 按规范化单词映射音频文件名，`let's` 对应 `lets.mp3`。
- 自定义单词如有 `audio_url`，可直接播放；没有音频时明确显示缺失状态，并跳过听力题。远端音频应使用可访问的 HTTPS 地址，并在小程序后台配置相应域名。
- 关闭「加入听力和自动朗读」后，综合模式不安排听力题，新词卡和答案均不自动朗读；仍可手动点击发音按钮。翻卡不会重复触发朗读，切到下一张新词卡会读新词；离开学习页会停止播放。
- 每页只持有一个播放器，切题、切后台或退出时销毁，播放失败可重听，听力题可切换为认词题。

更新词库或语音时，在安装英语语音及 FFmpeg 的 Windows 环境运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/generate-word-audio.ps1 -Ffmpeg 'C:\path\to\ffmpeg.exe'
```

Windows 脚本将 WAV 中间文件写入 `output/word-audio-source/`，把 24 kbps MP3 写入各自的资源包。macOS 可用以下命令补齐缺少的文件（默认保留现有音频，自动选择已安装的 Samantha 或 Eddy 美式英语语音）：

```bash
python3 scripts/generate-word-audio-macos.py --ffmpeg /path/to/ffmpeg
```

macOS 脚本使用临时目录存放中间音频，完成后自动清理。新增词条时同步补充课本内容与后端种子数据，并提交生成的 MP3；主包与每个分包均须小于 2 MiB。
