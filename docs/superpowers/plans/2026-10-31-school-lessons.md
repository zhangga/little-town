# 三科课堂扩展与小讲播

**Goal:** 保留鼠标/手指写字、数字口算、英语拼写，新增每科三种学习方式、五题课堂小练，以及能听、暂停、重听的分步讲解。

**Architecture:** school 分包内用统一题目结构承载选择、数字输入、组句、书写和拼写；纯函数产生题组与题目解法。独立讲解内容、音频播放器与页面方法模块，原有教材兼容。讲解使用随包发布的合成普通话音频，不依赖在线 TTS 或密钥。

## Steps

- [x] 新增 `curriculum.js`：12 种玩法及混合小练；题目自带提示、答案说明和关联小讲播，随机选项位置无固定答案。
- [x] 新增 `mini-lessons.js` 和 `lesson-player.js`：12 个主题、每课 3 步、播放/暂停/继续/重听/慢速、字幕、过期回调隔离，离开或切题停止声音。
- [x] 新增 `generate-school-audio.py`：macOS Tingting 普通话合成，AAC 单声道编码，缓存按文稿指纹失效；真实音频总量满足分包 2 MiB。
- [x] 更新课堂控制器与界面：玩法入口、选择题、组句、课堂小练回顾、不会时展开本题解法并听对应方法；独立小讲播目录和逐步板书。
- [x] 扩展本机存储：保留旧教材与次数，记录最近课堂小练结果。
- [x] 增加内容正确性、完整流程、暂停/切题/切科/退出、音频真实文件及包体积测试，更新真实模板预览并检查窄屏。
- [x] 更新使用说明，记录实际验证结果和仍需真机验证的部分。
