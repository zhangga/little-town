# 小镇生活 Implementation Plan

> **For agentic workers:** Execute the authorized implementation inline, task by task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 建筑和宠物购买后解锁对应生活事件，使用 1 金币模拟呼叫服务，让小镇有日常和伙伴。

**Architecture:** 独立 TownLifeService 管理宠物所有权、事件生成及处理；消费事务先锁用户行，与已有建造和学习共用锁。首页独立读取生活状态，保留原有角色与建筑逻辑。

**Tech Stack:** Go / Gin / GORM / MySQL，微信原生 WXML / WXSS / JavaScript，Go tests 和 Node test runner。
