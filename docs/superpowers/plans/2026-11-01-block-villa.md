# 方块别墅升级实施计划

**目标：** 保留橡木积木风，支持第一／第三人称切换，把实际房间大小接到房屋等级，增加可开关的方块木门，最终扩建成大别墅，并让所有可摆家具都能从商场买到。

**实现边界：** “升到什么样就有多大”按现有小屋升级解释。五级房屋占地依次为 7、9、12、16、20 格见方；升级保留家具坐标和所有权。外观与室内共享同一几何体，进入室内时隐藏遮挡外墙和屋顶。门可点击／E 键操作，开门后能经过门廊，WASD 和背包摆放继续有效。

- [x] 后端升级与空间：五级房屋资料、真实面积、价格及等级上限；动态占地校验；升级递增房间版本。
- [x] 三维建筑：像素橡木门、开关动画和通行检查；随等级增长的橡木／石砖／玻璃别墅，室内和完整外观视角。
- [x] 商场与家具：增加厨房、卫浴、娱乐等家具，补齐几何模型、货架图片、行为和购买到背包。
- [x] 人称切换：按钮或 V 切换；第一人称隐藏小人、显示手臂和准星，眼睛高度跟随走动；第三人称显示人物，遮挡的木门淡化；两种视角共用 WASD 和转动方向。
- [x] 页面呈现：升级显示面积和成长阶段；家里显示等级、开关门、查看外观；大户型镜头与寻路随空间大小适配；布置时进入全屋，保存／取消后恢复人称。
- [x] 验证：升级后的保存边界、旧布置、并发版本、真实数据库扣款、开关门通行、商城新家具、WebGL 交互与多尺寸布局。
