# 方块世界的自然效果与可携带合成物

目标：把光影、风、水、真实矿物和反射建材接入默认方块世界，使用同一背包、放置规则和存档。

1. 扩展世界地形：两种维度的浅河、可涉水碰撞、矿洞露出矿脉；旧修改优先于生成地形。
2. 扩展合成：石英、银、铜、萤石；白玻璃和镜子可合成、放置、回收，镜面方向保存。
3. 扩展分块渲染：全局阳光软阴影、随风叶片、缓慢水纹、环境反射、最多两面近处镜子的平面反射。
4. 兼容旧林溪成品：以可重试、可去重的转移记录把玻璃/白玻璃/镜子带入世界背包。
5. 验证：世界模拟回归、矿洞到合成到家中摆放的完整链路、存档与转移失败重试、实际 WebGL 画面和手机尺寸。

不改钱包与购买所有权。世界继续按账号与环境保存在本机。浏览器检查不能替代微信真机性能验收。

## 完成与验证

- 已接入两维度共用的光照、1024 软阴影、叶片与影子风动、浅河慢水纹和涉水移动。
- 已生成洞壁可直接挖取的真实矿脉和地下分布；白玻璃、银镜使用世界合成与背包，镜面朝向随位置保存，挖下完整回收。
- 已实现共享 128 环境探针、最多两面 384 平面倒影和第一人称角色倒影；反射过程中隐藏手、准星和放置提示。
- 林溪的三类玻璃成品通过待转移记录与世界接收记录带回，三处写入失败均验证可重试且不复制。
- 98 项房间、控制、林溪、方块世界与新增自然逻辑测试通过；世界原有浏览器流程与新增自然浏览器流程均通过。新增流程实际检查水/叶片像素变化、洞中石英采集、合成到家中摆放/回收/转向/读档、镜面预算、维度切换，以及 320/390/768 布局，无 WebGL 错误。
- 兼容工作区同时进行的微信原生画布控制改动；测试使用最新实际 WXML/WXSS 与控制器生命周期。尚未做微信真机性能验收或线上发布。
