# 小镇生活

小镇首页现在有生活手账、在建筑之间散步的居民与宠物、晨间/午后/夜晚氛围。首页提醒可以直接定位到当前事件；地图在对应服务建筑上显示事件图标。事件完成后展示结局，并保留最近三件小事。

## 建筑之间的日常活动

小镇长、园丁邻居和探险家邻居会沿建筑行间的草地、列间的空隙散步。每人独立选择下一处建筑，转弯时调整朝向，行走时轻轻摆动，到达后停留约 2～4 秒，说一句“买点面包”“看看花儿”等日常话语再出发。只有一座小屋或还没有建筑时，可以到草坪和花丛附近走走。

每只已拥有的健康宠物都独立活动，猫狗使用全身素材，有不同的速度；购买后即可加入散步。宠物生病时留在家里休息，处理完事件后恢复活动。居民生病时小镇长留在家中，其他邻居继续生活。地图不再在家门口重复显示健康的角色或宠物，也不再使用底部横向散步条。

人物和宠物的朝向由当前路段的位移决定：向上走用背面，向下走用正面，向左、向右用各自的侧面。转弯开始时切换素材，停留时保持最后朝向。四套服装与猫狗都有完整四方向素材，避免上下移动时继续朝左右看，也不再靠正面图的镜像冒充转身。映射在 `miniapp/utils/stroll-art.js`，素材与生成提示词见 `output/imagegen/walk-directions-prompt.md`。

路线模块为 `miniapp/utils/town-stroll.js`。路线根据当前三列地块生成，只沿水平通道和列间空隙移动；地图每行 272rpx，行间留 72rpx，路线与 WXSS 布局保持一致。空地仍可点击建造，散步层不拦截触摸。草地纹理数量随新地图高度增加。

移动由 WXSS transition 完成，计时器仅在转弯和停留时更新状态。普通余额刷新保留路线，离开页面会清理计时器，返回后继续，卸载后不再回写；系统减少动态效果时关闭位移过渡和步行动画。散步不发起服务消费，也不改变资源。

没有对应建筑时，候选事件池不会包含该事件。只有宠物医院、只有宠物，或者宠物搭配普通医院，都不会解锁宠物生病。服务处理时会再次检查建筑、宠物所有权，所有价格均由后端决定。

小狗豆豆、小猫团团各 20 金币，购买前先预览，确认按钮标明价格。买一次永久拥有，可同时拥有两位伙伴；拥有后会在建筑之间散步，生病时回家休息。宠物医院图纸需要 10 砖块，复用医院图集并用爪印和名称区分。

底部常驻「🐾 买宠物」按钮，点击直达宠物商店；生活服务未连上时会先重试读取。商品卡明确显示「购买 · 20 金币」，已拥有的伙伴显示「✓ 已入住」并禁止重复购买，金币不足时可前往学习。商店使用 180rpx 的猫狗全身图，购买预览和入住反馈使用 240rpx 大图；地图中散步及在家休息的宠物使用 96rpx 全身素材，散步尺寸从 64rpx 放大 50%，脚底位置和四方向朝向保持一致。所有展示复用同一张宠物图集，不增加素材体积。

## 节奏与资源

- 首次拥有可体验内容后，下次读取生活状态会随机出现一件符合条件的小事。
- 每次最多一件待办；处理后至少间隔 2 小时，下次进镇或刷新时才会出现新事件，每个本地自然日最多生成三件。连续两件尽量不同。
- 待办跨日保留，离线不生成积压；事件不升级、不损毁建筑、不自动扣款。等待处理没有资源惩罚。
- 所有电话都在游戏内模拟，没有系统电话调用。医生、消防、宠物医生、警员的帮助均只需 1 金币。
- 余额不足时保留待办，并提供学习入口；免费日常在 0 金币时也可完成。
- 读取、购买、处理均在数据库事务中先锁用户行，与建造、学习奖励和角色消费协调。相同宠物重复购买、相同事件重复处理均不重复扣款。
- 前端消费期间锁定按钮，刷新期间不允许发起消费；响应结果不明时读取最新状态，不重发扣款请求。生活服务失败时，地图和角色仍可使用。

## 接口与发布

以下接口需要现有登录令牌，前缀为 `/api/v1`：

| 方法 | 路径 | 请求 |
| --- | --- | --- |
| GET | `/town-life` | 无；会按节奏生成待办 |
| POST | `/town-life/pets/purchase` | `{"pet_id":"dog"}` 或 `{"pet_id":"cat"}` |
| POST | `/town-life/events/resolve` | `{"event_id":123}` |

均返回 `wallet`、`pets`、`buildings`、`event`（无待办时为 null）、`recent` 和 `unlocked_count`。写操作只接收物品/事件标识，客户端不能指定消费价格。

新增 `town_pets`、`town_events` 两张表。`town_pets` 使用 `user_id + pet_id` 复合主键；事件索引为 `user_id + created_at`，`resolved_at` 为可空时间，未处理时保存 SQL NULL。

发布时同步更新后端和小程序，并执行迁移与建筑种子导入：

```bash
cd backend
go run cmd/import/main.go
```

该项目导入流程会迁移表结构，并按名称添加宠物医院；已有建筑和用户资源不需要重建。仅重启启用 AutoMigrate 的后端可以创建新表，但仍需导入新图纸。
